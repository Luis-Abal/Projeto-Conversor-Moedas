# 💱 Converter-Money

Um aplicativo simples para converter valores de **Real Brasileiro (BRL)** para outras moedas: **Dólar Americano (USD)**, **Euro (EUR)** e **Franco-Suíço (CHF)**.

---

## 🚀 Funcionalidades
- [Seleção de moedas](ca://s?q=Selecao_de_moedas_em_projeto) para conversão.
- [Entrada de valor](ca://s?q=Entrada_de_valor_em_projeto) em Real Brasileiro.
- [Exibição do resultado](ca://s?q=Exibicao_de_resultado_em_projeto) com valores formatados.
- Alteração dinâmica de nome e bandeira da moeda escolhida.
- Interface estilizada com cores, ícones e responsividade.

---

## 🛠️ Tecnologias utilizadas
- [HTML5](ca://s?q=HTML5_em_projeto) → Estrutura da aplicação.
- [CSS3](ca://s?q=CSS3_em_projeto) → Estilização e layout.
- [JavaScript](ca://s?q=JavaScript_em_projeto) → Lógica de conversão e manipulação do DOM.

---

## 🔑 Lógica de conversão
- Taxas fixas definidas no código:
  - Dólar: `5.2`
  - Euro: `6.2`
  - Franco-Suíço: `6.4`
- Uso da API `Intl.NumberFormat` para formatar valores conforme a moeda selecionada.
- Atualização dinâmica dos elementos HTML:
  - `.currency-value-to-convert` → mostra o valor em Real.
  - `.currency-value` → mostra o valor convertido.
  - `.currency-img` e `#currency-name` → mudam conforme a moeda escolhida.
